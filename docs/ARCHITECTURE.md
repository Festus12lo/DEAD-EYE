# Architecture

DEAD-EYE is a safety-first Windows systems laboratory. Core boundaries are Contracts, Intelligence Providers, Validation, Evidence, Benchmarking, Optimization Registry, Transaction Kernel, Trust Layer, and Presentation.

The canonical post-M6 baseline is read-mostly. Providers publish observations with provenance, confidence, freshness, and explicit unknown states. Optimization definitions are metadata and preview contracts. No provider or battery engine can write registry, services, tasks, files, power plans, firmware, drivers, or device registers.
